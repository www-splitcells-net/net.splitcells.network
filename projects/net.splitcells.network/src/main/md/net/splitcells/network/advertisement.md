# Feature Advertisement
* Comfortably model assignment problems with a fluent API.
* Contains an in-memory database system,
  providing tools to model and manage data with an extensive query system.
  A synchronized cache system enabling to make complex queries with a constant runtime.
* Get reports reasoning the solution's rating, equipping you with the tools to understand your problems.
* Model inter dependent problems in order to work on complex interactions.
* x64, ARM and RISC-V are supported and tested.
