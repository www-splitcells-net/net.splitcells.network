# Feature Advertisement
* Supplies a simple and powerful assignment model for problems inspired by relational databases,
  that is paired with a web IDE.
* Model complex systems by linking multiple simple problems together.
  This allows you to create a toolbox for rapid modeling of processes. 
* Clean and detailed analysis of solutions help to semantically understand the results.
* Deployable as a local application or server.
  Alternatively, just use the cloud instance on the fly.
* Provides an in-memory database for developers, in order to develop capable optimizers.
* x64, ARM and RISC-V computers are supported and tested.
